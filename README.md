One word for your Wi-Fi: **ghosting**. Home Wi-Fi that vanishes mid-call, mid-show, mid-sentence — exactly when you need it most — then drifts back pretending nothing happened. The funniest and truest description of Wi-Fi as it is actually lived, and a fitting name for the sponsor's network.

## Run it

```sh
node main.ts
```

This writes the single word `ghosting` to `/output/entry.txt` (no trailing newline, no extra text).
